# Управление страницей «О компании»

Войдите в `/admin`. Нажмите **О компании** в левом меню или на главной админки. Сразу откроется список секций страницы. Прямой адрес — `/admin/about`. Настройки SEO расположены ниже в этой же форме. Права редактора достаточны для правки страницы. Настройки компании меняет администратор.

| Что изменить | Как это сделать |
| --- | --- |
| Первый экран | Раскройте «Первый экран». Заполните надзаголовок, заголовок H1, подзаголовок, описание и текст кнопки. Выберите действие. Для раздела сайта используйте список, для страницы CMS — связь со страницей. Внешний адрес должен начинаться с HTTPS. |
| Текст знакомства | В «Знакомство с компанией» измените абзацы в визуальном редакторе. Выделите текст для форматирования или добавления ссылки. Для внутренней посадочной выберите документ Pages. Можно прикрепить иллюстрацию и поставить её слева или справа. |
| Преимущество | В секции «Преимущества» добавьте карточку, введите название и описание. Для библиотечной иконки введите в поиске, например, Clock, затем нажмите на рисунок. «Очистить выбор» убирает иконку. Для собственной иконки выберите режим загрузки изображения. |
| Услуга | В «Компетенции и услуги» добавьте карточку и выберите существующую услугу. Название и краткое описание по умолчанию берутся из каталога. Два альтернативных поля меняют их только на этой странице. Ссылку настройте в самой услуге. Снятие услуги с публикации убирает карточку с сайта. |
| Этапы | В «Этапы работы» добавьте заголовки, описания и при необходимости иконки. Номера видимых этапов сайт расставит сам. |
| Порядок и видимость | Перетащите секцию или строку за маркер порядка. Используйте меню строки для перемещения и удаления. Снимите «Показывать на сайте», чтобы временно скрыть содержимое. Пустая сетка также исчезнет. |
| Команда | Раскройте «Наша команда». Первоначально секция скрыта. В строке сотрудника можно указать ФИО, должность, описания и портрет. Без имени на сайте отображается должность. У иллюстративного портрета поставьте флажок, чтобы посетитель видел подпись. Включите секцию после подтверждения материалов. |
| Изображение | В поле изображения нажмите «Создать» для загрузки либо «Выбрать из существующих». Выберите файл JPEG, PNG, WebP или AVIF. Укажите описание изображения. В медиатеке можно настроить точку фокуса. Декоративная картинка получает пустой alt. |
| Реквизиты | Откройте **Система → Настройки компании → Публичные реквизиты**. Сверьте юридическое наименование, ИНН ИП, ОГРНИП, дату регистрации и публичный почтовый адрес с документами. Заполняйте только необходимые поля. После сверки включите флажок подтверждения и сохраните настройки. |
| Публичный документ | В **Контент → Публичные документы** загрузите PDF до 10 МБ. Укажите название, по желанию описание и дату. После проверки персональных данных разрешите публичное скачивание. В секции страницы «Документы и реквизиты» добавьте строку и выберите этот файл. Отключение доступа в коллекции закрывает и прямую ссылку на файл. |
| Заключительное обращение | Измените заголовок, описание, подписи кнопок и дополнительную строку. Телефон и режим работы берутся из настроек компании. Флажок режима работы позволяет убрать эту строку. |
| SEO | На вкладке **SEO** задайте Title, Description, тексты и изображение для соцсетей. В «Техническое SEO» доступны canonical и флаги индексации. Обычно поле canonical оставляют пустым. |
| Черновик и публикация | Нажмите **Сохранить черновик**, чтобы вернуться к работе позже. Посетители видят последнюю опубликованную версию. Для выпуска нажмите **Опубликовать изменения**. История доступна в пункте «Версии». Снятие всей записи с публикации убирает страницу и её адрес из sitemap. |

После публикации откройте `/about` в отдельном окне. Проверьте заголовок, порядок карточек, ссылки, мобильную версию и открытие формы обратного звонка. В исходном HTML страницы можно проверить Title, description и canonical. Редактирование черновика доступно после авторизации в Payload. Отдельного публичного URL для черновиков в проекте нет.
