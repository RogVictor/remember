# Ритуальная служба «Память» — Next.js подготовительная версия

Перенесён интерфейс из экспорта Figma Make в Next.js App Router с сохранением исходных CSS-стилей и основных компонентов.

## Локальный запуск

Требуется Node.js 20.9+.

```bash
npm install
npm run dev
```

Откройте http://localhost:3000.

## Маршруты

- `/`
- `/services`
- `/funeral`
- `/products`
- `/prices`
- `/about`
- `/info`
- `/faq`
- `/contacts`
- `/legal`

## Статус

Это подготовительная версия интерфейса, не production-релиз. Payload CMS, PostgreSQL, запись заявок и уведомления Telegram/email ещё не подключены. Форма обратной связи остаётся демонстрационной и не должна использоваться для реальных заявок.

Контактные данные и цены содержат заглушки/неполные данные. Перед публикацией замените их подтверждённой информацией компании, добавьте юридически проверенные документы по обработке персональных данных и подключите серверную обработку форм.

Индексация поисковиками отключена намеренно через metadata и `app/robots.ts` до завершения проверки контента.

## Следующий этап

1. Проверить production build и все маршруты.
2. Подключить Payload CMS и PostgreSQL.
3. Сделать серверный обработчик заявок и уведомления.
4. Заполнить достоверные сведения о компании и проверить требования законодательства РФ к персональным данным.
5. Настроить VPS, HTTPS, резервное копирование и только после проверки включить индексацию.
